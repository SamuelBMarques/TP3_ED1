# 📚 Estruturas de Dados I — TP3

Implementação de diferentes **estruturas de dados em C**, desenvolvida como trabalho prático da disciplina de **Estruturas de Dados I (ED1)**.

O projeto reúne implementações de listas encadeadas e tabelas hash, explorando diferentes estratégias de armazenamento e busca de dados.

---

## 🧩 Estruturas implementadas

### 🔗 Lista Encadeada

Implementação de uma lista encadeada utilizando nós e ponteiros.

Principais operações:

* Inserção
* Remoção
* Busca
* Percurso da lista

### #️⃣ Tabela Hash — Endereçamento Aberto

Implementação de uma tabela hash utilizando **endereçamento aberto** para armazenar e buscar elementos.

### #️⃣ Tabela Hash — Duplo Hashing

Implementação de uma tabela hash utilizando **duplo hashing** como estratégia de resolução de colisões.

```bash

./programa
```
